<p 

Machine learning algorithms implemented in this project:

- 🌟 XGBRegressor: Achieved the highest accuracy among all evaluated models.

- 📈 Lasso Regression

- 📉 Ridge Regression

- 🐱 CatBoost

- 🌱 Gradient Boosting

- 💡 LGBM

- ➗ Linear Regression

</br></br>

<p 

Models were evaluated based on these metrics:

- R-squared

- Mean Absolute Error (MAE)

- Root Mean Squared Error (RMSE)

- Mean Squared Error (MSE)

</p>

<h2>🧐 Features</h2>

Here're some of the project's best features:

*   ✅ Predict Scores: Estimate team scores based on match conditions and historical data.
*   ✅ Win Probability: Determine the likelihood of a team's victory.
*   ✅ Advanced Algorithms: Utilizes multiple regression models to achieve high accuracy.
*   ✅ Real-Time Predictions: User-friendly mobile app for predictions on the go.
</br></br>
  
  
<h2>💻 Built with</h2>

Technologies used in the project:

*   Python: For data processing and model training. 🐍
*   Flask: For building the backend API. 🔗
*   Flutter: For the mobile application frontend. 📱
*   Jupyter Notebook: For exploratory data analysis and model development. 📘
*   Scikit-learn XGBoost CatBoost LightGBM: For machine learning algorithms. 🤖

</br></br>

<p

Follow these steps to use the project:

- Clone the repository.

- Navigate and run the Jupyter notebooks for data exploration and model training.

- Deploy the backend by running the Flask application located in the 'app/' folder.

- Build and deploy the Flutter application for real-time predictions.
